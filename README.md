# 선생님을 위한 문서 업무 도우미

기존 양식과 참고자료를 주면 내용을 채워 초안을 만들어 줍니다.

## 1. 처음 한 번, “설치해줘”

[다운로드](https://github.com/ray-math/teacher-harness-release/archive/refs/heads/main.zip)한 파일의 압축을 풀고, 그 폴더를 Codex에서 엽니다. Codex 설치와 로그인은 먼저 해 주세요.

채팅에 아래 한마디를 입력하세요.

> 설치해줘.

설치할 때 작은 한글 예제로 읽기·수정·저장이 되는지도 확인합니다. 준비가 끝났다는 안내를 받으면 같은 폴더에서 새 채팅을 열어 업무를 시작합니다.

## 2. 자료를 주고, 하고 싶은 일을 말하세요

**기존 양식이나 작년 문서**, **올해 반영할 자료**를 준비하고, 자료가 있는 폴더를 알려 주세요.

> 바탕화면의 ‘행사자료’ 폴더에 있는 자료를 보고, 작년 안내문의 형식에 맞춰 올해 내용으로 바꿔 줘.

강의에서 받은 연구회 신청 예제는 `강의시연자료_연구회신청` 폴더를 바탕화면에 둔 뒤, 아래 문장을 그대로 입력하면 됩니다.

> 바탕화면의 ‘강의시연자료_연구회신청’ 폴더에 있는 자료를 보고, 기존 신청양식과 안내공문의 서식은 그대로 유지하면서 올해 연구회 신청서·연구계획서와 신청 제출공문 초안을 작성해 줘.

완성된 초안은 **바탕화면의 `Output` 폴더**에 `00_제목`, `01_제목` 순서로 저장됩니다. 제공한 원본은 그대로 둡니다.

파일을 열어 확인하고, 부족한 부분은 이어서 말하세요.

> 연구계획서의 세부 활동을 조금 더 구체적으로 써 줘.

> 행사 날짜를 5월 20일로 바꿔 줘. 나머지는 그대로 둬.

초안의 날짜·이름·금액을 확인한 뒤 사용하세요. 서명·결재·실제 제출은 선생님이 진행합니다.

## 3. 한글 문서 작업, 이렇게 맡겨 보세요

안내문·공문·계획서·보고서·회의록·신청서·명단 등, 선생님이 한글로 하던 문서 작업을 도와줍니다. 아래는 대표적인 작업 범위입니다. 문서 이름이 목록에 없어도 필요한 일을 말해 주세요.

| 작업 | 맡길 수 있는 내용 |
|---|---|
| 읽고 정리하기 | 긴 문서 요약, 주요 내용과 일정 찾기, 여러 자료에서 필요한 정보 모으기 |
| 초안 작성하기 | 기존 양식에 맞춰 안내문·공문·계획서·보고서 등 작성, 메모를 문서 문장으로 정리 |
| 내용 수정하기 | 올해 내용으로 갱신, 문장 다듬기, 설명 보충, 내용 줄이기, 지정한 부분만 변경 |
| 표와 명단 다루기 | 표의 빈칸 채우기, 같은 양식의 명단 취합, 중복·누락 찾기, 금액과 합계 확인 |
| 자료 비교하기 | 원본과 수정본의 차이 찾기, 문서와 엑셀 대조, 이름·날짜·인원·예산의 불일치 확인 |
| 서식 정리하기 | 글자 크기·문단 간격·정렬·표 모양 등 원하는 부분의 서식 수정 |
| 반복 작업 돕기 | 같은 양식에 서로 다른 자료를 넣기, 여러 문서의 공통 문구 수정 |

작성할 때는 기존 양식이나 이전 문서와 참고자료를 함께 주세요. 기본적으로 기존 서식을 유지하며 내용을 채웁니다. 서식까지 바꾸고 싶으면 바꿀 부분을 말해 주세요. 파일 형식이나 설치된 프로그램에 따라 가능한 작업이 달라질 수 있으며, 실제 한글 화면의 쪽 나눔과 배치는 결과를 열어 확인하세요.

초안을 받은 뒤에도 짧게 이어서 요청하면 됩니다.

> 이 부분을 더 자세히 써 줘.

> 이 내용은 빼 줘.

> 표의 제목을 가운데로 맞춰 줘.
