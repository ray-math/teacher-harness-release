# 교사 연수 실습자료

**실제 학교·학생 자료가 없는 가상 예제**입니다. 설치한 프로젝트의 채팅에서 아래 상대경로를 그대로 사용합니다. 별도 다운로드 링크를 찾을 필요 없이 저장소 첫 화면의 **Code → Download ZIP**으로 받은 폴더 안에 함께 들어 있습니다.

Markdown(`.md`)은 텍스트 문서입니다. GitHub에서는 내용을 바로 볼 수 있고, 컴퓨터에서는 텍스트 편집기로 열 수 있습니다. 이 실습은 요청 범위 보존과 근거 확인을 연습하며, HWPX·ODT·엑셀의 서식 보존이나 한컴 프로그램 연결을 검증하는 실습은 아닙니다.

## 실습 1 — 기존 안내문의 날짜·장소만 수정

사용 자료: [기존 안내문](01_기존안내문.md), [행사 메모](02_행사메모.md)

프로젝트 채팅에 다음 요청을 넣습니다.

> `docs/실습자료/01_기존안내문.md`를 기준본으로 열고 `docs/실습자료/02_행사메모.md`에 따라 날짜와 장소만 수정해 줘. 제공 자료의 원본 사본을 받은자료에 보관하고, 원본 파일은 수정하지 마. 결과는 설정된 업무폴더의 실습 업무에 저장해 줘. 나머지 문구·항목·순서는 유지하고, 변경 전후와 저장 위치를 알려 줘.

확인할 것:

- 날짜가 `2026년 11월 12일`, 장소가 `별빛학교 시청각실`로 바뀌었는가?
- 시간·대상·준비물·참가비·인사말·문서 구조가 유지됐는가?
- 원본과 결과 파일을 각각 열어 비교할 수 있는가?

## 실습 2 — 기존 표의 빈 칸을 근거로 채우기

사용 자료: [기존 계획표](03_기존계획표.md), [근거 메모](04_근거메모.md)

> `docs/실습자료/03_기존계획표.md`를 기준본으로 열고 `docs/실습자료/04_근거메모.md`에서 근거를 찾아 빈 칸을 채워 줘. 제공 자료의 원본 사본을 받은자료에 보관하고, 원본 파일은 수정하지 마. 표의 열·행과 기존 내용은 유지해 줘. 충돌하거나 근거가 없는 값은 내용 칸을 비워 두고 근거·확인 상태에 이유를 표시해 줘. 결과는 설정된 업무폴더의 실습 업무에 저장하고, 확인이 필요한 항목과 저장 위치를 알려 줘.

확인할 것:

- 일시·장소가 근거 A에 따라 채워졌는가?
- 참가 예정 인원의 내용 칸은 비어 있고, `48명 / 50명 충돌·확인 필요`가 표시됐는가?
- 총예산의 내용 칸은 비어 있고, `근거 없음·확인 필요`가 표시됐는가?
- 행사명·대상·준비물·운영 원칙과 표 구조가 유지됐는가?

## 결과를 확인한 뒤

AI의 완료 보고만 보지 말고 결과 파일을 직접 엽니다. 원본, 변경한 내용, 미확정 항목을 확인한 뒤 사용합니다. 입력 자료를 삭제해도 된다고 요청하기 전에는 원본 사본을 지우지 않습니다. 업무 분류가 아직 없다면 실습용 업무명을 정해 달라는 질문에 답합니다.
