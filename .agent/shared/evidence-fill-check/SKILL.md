# 근거로 채우고 대조하기

사용자가 선택한 현재 자료와 이미 확정한 기준을 사용한다. 자료가 충분하면 이전 연도를 추가 검색하지 않는다. 확인만 요청하면 파일·접수·현재본을 변경하지 않고 근거와 판정을 채팅으로 답한다. 작성은 [문서 처리](../../../.agents/skills/hwpx-workspace-delivery/SKILL.md)의 같은 job과 형식별 도구를 사용한다.

기존 양식과 근거를 읽어 학년·대상·단위·기준일로 항목을 대응시킨다. 병합 표는 라벨과 값칸을 구분하며 좌표·파일 수만으로 의미를 판단하지 않는다. 실제 제출값과 예시값, 공란·0·해당 없음·자료 없음을 구분한다. 근거 충돌은 사용자가 정한 해결 기준을 따르고, 해결되지 않은 항목은 기존 실제 값을 보존하며 미확정으로 남긴다. 나머지는 계속 채운다. 합성 시나리오는 그 시나리오의 기준을 따른다.

일반 초안은 편집 계획에 필요한 근거 위치와 변경값만 짧게 남긴다. 별도 전항목 sourceRef·판정표·검증보고·필수 프로필을 만들지 않는다. 업무프로필은 필요한 매핑의 참고로 읽고 일치하지 않는 항목만 미확정으로 둔다.

저장본에서 실제 채운 핵심값·반복값 표본, 관련 합계, 예시·옛 날짜가 남기 쉬운 위치와 요청 밖 내용 보존을 **한 번 확인**한다. 형식별 실행기의 원본 해시·dry-run·저장·재열기 검사는 그대로 유지한다. 같은 입력·출력·도구 버전의 성공 기록은 재사용하고, 표본 검사를 전항목 완료로 보고하지 않는다. 실패 시 저장 여부와 원인을 확인해 해당 부분만 복구한다. 원시 HWPX ZIP/XML을 직접 쓰거나 열기 안전 실패를 무시하지 않는다.

초안 게시 후 보완사항은 중요한 순서로 최대 3개, `남은 항목 — 필요한 자료 또는 다음 작업`으로 채팅에 제안한다. 문안 완성도를 위한 자동 수정 반복은 하지 않는다. Review는 검토용 초안이다.
