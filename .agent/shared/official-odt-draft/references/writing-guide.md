# 공문 작성 기준

아래는 원문 전문이 아니라 이 스킬에 필요한 요약이다. 서식·표기 근거와 업무 사실 근거를 구분한다. 제도 변경이 의심되거나 현행 규정 자체를 묻는 경우에만 공식 원문을 다시 확인한다.

모든 작성·수정은 사용자가 지정한 기존 초안/양식을 먼저 실제 읽고 그 구조에 내용을 채운다. 기준 파일이 없으면 반드시 멈춰 질문한다. 아래 예제 글꼴·줄간격·여백·표 기본값은 새 문서 양식을 생성하거나 기존 양식 전체를 바꾸는 허가가 아니다. 지정 원본 형식을 유지하며 자동 ODT 변환을 하지 않는다.

## 배포 예제의 미확인 표기

**공식 편람을 항상 우선한다.** 숫자 0은 미확인 값의 표식이며 유효한 날짜가 아니다. 배포 예제의 미확인 표기도 편람의 월·일 선행 0 생략 방식에 맞춰 `0000. 0. 0.`으로 쓴다. 이전 양식의 잘못된 표기를 따르지 않는다.

| 확인 상태 | 초안 표기 예 |
|---|---|
| 기관·번호·날짜 모두 미확인 | `00고-0000(0000. 0. 0.)` |
| 기관만 확인 | `예시고등학교-0000(0000. 0. 0.)` |
| 기관·번호만 확인 | `예시고등학교-1234(0000. 0. 0.)` |
| 연·월만 확인 | `00고-0000(2026. 9. 0.)` |
| 모두 확인된 가상 예 | `예시고등학교-1234(2026. 9. 4.)` |

표의 1234와 날짜는 설명용 가상 값으로 실제 공문 인용에 사용하지 않는다. 기관명은 확인된 정식 명칭을 보존한다. 문서번호 바로 뒤에 여는 괄호를 쓰고 일의 마침표 뒤에 닫는 괄호를 쓴다. 날짜 뒤에 요일은 필요할 때만 넣는다. 관련 표기는 배포 예제 기준이며 기관 양식과 현재 사용자 지정이 우선한다.

여러 관련 문서는 다음처럼 나눈다.

```text
1. 관련
  가. 00고-0000(0000. 0. 0.)
  나. 00고-0000(0000. 0. 0.)
2. [요청 목적에 맞춘 본문]
```

아예 관련 문서가 없는 업무와, 관련 문서는 있으나 식별 정보가 미확인인 업무를 구분한다. 전자는 관련 항목을 생략할 수 있고 후자는 공란 표시를 사용한다. 법령·지침명만 근거인 경우 공문번호로 꾸미지 말고 확인한 근거명을 그대로 쓴다.

## 기본 서식 필수 검사

굴림체 12pt·장평 100%·자간 0은 배포 빈자산/합성 도우미 자체의 예제값이다. 업무에서는 사용자 지정 기존 양식의 글꼴·크기·장평·자간을 보존하고 명시 요청한 속성만 해당 범위에서 바꾼다. 편람의 보편적 의무 글꼴로 설명하지 않는다. 적용 대상의 한글·영문·숫자·표·붙임에서 실제 상속 글꼴과 구간별 덮어쓰기를 확인한다. 글꼴이 없으면 대체 글꼴로 검증됐다고 보고하지 않는다.

공문 초안에서도 다음을 모두 대조한다. 확인 요청만이면 파일을 변경하지 않고 항목별 결과를 보고한다.

- 문서 식별: 기관명·문서번호·괄호·날짜 사이 공백과 마침표, 관련 문서의 번호/날짜 근거. 미확정 번호는 공란 정책대로 두고 제출 전 미확인 사항으로 구분한다.
- 항목: 같은 단계의 번호 연속성과 `1. → 가. → 1) → 가) → (1) → (가) → ① → ㉮` 단계, 항목이 하나일 때 불필요한 번호 생략. 번호 없는 독립 항목이 섞이면 상하 관계부터 판단한다.
- 위치와 공백: 첫째 단계는 왼쪽 기본선, 하위 단계는 2타씩 들여쓰기, 항목기호 뒤 1타. 이 배포본 예제는 이어지는 줄을 본문 첫 글자에 맞추는 문단 내어쓰기로 통일한다. 실제 글꼴 폭을 측정하며 글꼴 변경 전 좌표를 그대로 재사용하지 않는다.
- 붙임: 제공 자료별 목록·수량 대응, 두 종류 이상이면 번호 순서, `붙임` 뒤 2타와 번호 뒤 1타에 해당하는 간격, 번호 열과 자료명 시작 열 및 이어지는 줄 맞춤, 마지막 자료 뒤 2타와 `끝.`. 여러 붙임은 번호 앞에만 탭을 두어 번호 시작점을 맞춘다. 번호의 마침표 뒤는 탭 없이 실제 공백 한 칸을 쓰고, 이어지는 줄은 해당 자료명 첫 글자 위치에 문단 내어쓰기로 맞춘다. 번호 자릿수가 다르면 각 번호와 공백의 실제 폭으로 내어쓰기 위치를 계산한다. 첫 줄 접두어의 글자 폭과 다음 줄 숫자 들여쓰기를 서로 다른 방식으로 맞추지 않는다. 탭 좌표가 문단 왼쪽 들여쓰기를 기준으로 해석되는지도 확인한다. 저장 속성의 일치만으로 실제 정렬 통과를 선언하지 않는다.
- 저장 후 검사: 정확한 현재본과 변경 범위를 비교하고, 재연 파일의 문단/글자 속성을 상속과 직접 서식까지 확인한다. 단순 텍스트 추출이나 ZIP 정상 여부는 정렬 검사가 아니다. 실제 편집기에서 확인하지 못한 표시 결과는 미검증으로 남긴다.

이 기본 서식은 새 공문 작성 범위에 포함한다. 기존 파일 후속 수정의 범위 제한, 읽기 전용 확인 요청, 표 내부 줄바꿈이나 페이지 미관의 별도 권한은 그대로 따른다.

## 표 공통 편집 기준

아래는 이 배포본의 **공문 본문 표 예제 기본값**이다. 법정 의무 수치나 모든 기관의 관행으로 설명하지 않는다. 새 공문 작성과 표 편집이 요청된 범위에 적용하며, 기관 지정 양식과 사용자의 별도 지시를 우선한다. 기존 공문·결재란·서명란을 기본값 변경만으로 일괄 수정하지 않는다.

| 항목 | 공통 기본값과 조정 원칙 |
|---|---|
| 표 앞뒤 | 표 위·아래 각각 6pt를 시작값으로 하고 문서 안에서 통일한다. 빈 문단을 여러 번 넣지 않고 문단/표 간격 속성으로 설정한다. 인접 문단 여백과 중복되어 실제 간격이 커지지 않는지 확인한다. |
| 위치·너비 | 표가 속한 항목을 먼저 확인한다. `가.` 아래 표는 `.`의 문자 시작점, 그 하위 `1)` 아래 표는 해당 `)`의 문자 시작점에 왼쪽 테두리를 맞춘다. `1. → 가. → 1) → 가) → (1) → (가) → ① → ㉮` 전 단계에 같은 원칙을 적용하며, 마지막 구두점이 없는 원문자는 그 문자 시작점에 맞춘다. 연결 항목이 없는 독립 표는 왼쪽 기본선에서 시작한다. 들여쓴 만큼 사용 가능 폭에서 빼고 열 너비의 합이 그 폭을 넘지 않게 한다. |
| 열 너비 | 균등 분할을 강제하지 않는다. 이름·구분처럼 짧은 열보다 기관명·기간·설명처럼 긴 열에 폭을 더 배분한다. 의미와 실제 길이를 보고 결정한다. |
| 글자 | 본문과 같은 굴림체 12pt를 우선한다. 별도 지정이 없으면 장평 100%, 자간 0. 공간 부족을 이유로 글꼴·크기·장평부터 바꾸지 않는다. |
| 가로 정렬 | 열 제목과 짧은 이름·구분은 가운데, 긴 설명은 왼쪽, 비교할 수량·금액은 오른쪽 정렬한다. 숫자로 보인다는 이유만으로 날짜·문서번호·식별자를 수량처럼 처리하지 않는다. |
| 셀 여백 | 사방 1~2mm를 시작 범위로 사용한다. 생성 도우미의 초기값은 1.5mm이다. 내용이 테두리에 붙거나 불필요하게 줄바꿈되지 않도록 조정한다. |
| 줄바꿈·쪽 나눔 | 먼저 열 너비와 배치를 조정해 이름·날짜·짧은 항목이 불필요하게 끊기지 않도록 한다. 공백·강제 줄바꿈을 대량 삽입해 모양을 맞추지 않는다. 작은 표는 가능한 한 한 쪽에 두고, 긴 표는 제목행을 반복한다. |

표 정렬은 배포 예제 편집 기준이며 기관 양식과 현재 사용자 지정이 우선한다. 실제 항목기호 시작 위치(문단/목록 들여쓰기 반영)에 마지막 `.`/`)` 앞 문자들의 실제 글꼴 폭을 더한다. 본문 첫 글자 맞춤과 구분한다. 예를 들어 굴림체 12pt에서 `가.`의 기호 시작이 12pt이면 표 시작은 24pt, `1)`의 기호 시작이 24pt이면 표 시작은 30pt다. 이는 예시이며 다른 크기·글꼴·들여쓰기에 고정 좌표를 재사용하지 않는다. 상위 항목 전체의 표라면 중간에 하위 항목이 있어도 상위에 귀속하며, 단순히 직전 문단을 자동 선택하지 않는다. 문자 시작점은 점/괄호의 검은 잉크 중심이 아니다.

표 앞뒤 간격, 열 너비 합, 셀 여백, 역할별 정렬과 글자 속성은 저장 후 구조 검사에 포함한다. 실제 줄바꿈·여백의 보이는 크기·페이지 분리는 편집기 렌더링을 확인한 경우에만 통과로 보고한다. 서식 수치가 저장됐다는 사실은 화면 검증을 대신하지 않는다.

## 내용 작성과 대조

제목은 행위와 대상을 드러내는 짧은 문구로 쓴다. 본문은 근거, 목적, 핵심 사실 또는 요청 사항, 붙임의 흐름을 기본으로 하되 업무에 필요하지 않은 항목은 만들지 않는다. 구체적 날짜·장소·대상·의결 내용·금액을 관행이나 이전 회차로 채우지 않는다.

원문에 등록일·결재일·시행일이 함께 있으면 각각의 역할을 구분한다. 관련 인용 날짜는 그 문서의 정식 시행/등록 정보와 문서 성격을 확인해 고른다. 역할이 불명확하면 공란을 남긴다. 증거 기록에는 선택 원문 경로·위치·해시와 확인된 요소만 남기고 학교 내부 내용을 공통 색인에 옮기지 않는다.

표준 붙임 예(내용과 수량은 가상):

```text
붙임  자료명 1부.  끝.
```

```text
붙임  1. 첫 번째 자료명 1부.
      2. 두 번째 자료명 1부.  끝.
```

문서 안에는 초안 본문에 필요한 공란만 남긴다. 작성자용 장문의 검토 메모·출처 URL·검증 로그는 본문에 끼워 넣지 말고 요청된 채팅 보고 또는 기존 업무 콘솔에 남긴다.

## 줄간격 편집 기본값

이 배포본의 수신·제목·본문·본문 표·붙임 줄간격 예제 기본값은 123%이다. `typography.line_height`로 양의 백분율 문자열(예: `160%`)을 지정할 수 있으며 기관 양식과 현재 사용자 지정이 우선한다. 기관명·상징·슬로건·결재 서식은 별도 양식 역할을 보존한다. 국가의 공통 의무 백분율로 설명하지 않는다. [2026년 7월 기준 학교업무매뉴얼](https://www.goe.go.kr/goe/cm/cntnts/cntntsView.do?cntntsId=1468&mi=10557)에 포함된 ‘한곳에 정리한 공문서 작성법’ 7쪽의 기본값 123% 안내와 제공 공문의 본문값을 참고한 편집 선택이다. 장평 100%와 줄간격 123%는 별개 속성이다. 기관 지정값·사용자 별도 지시가 우선한다.

## 최신 자료 대조 및 붙임 앞 구분

[2026년 7월 기준 경기도교육청 중등 학교업무매뉴얼](https://www.goe.go.kr/goe/cm/cntnts/cntntsView.do?cntntsId=1468&mi=10557)의 공통행정 묶음을 참고한다. 묶음에 포함된 2025 행정업무운영 편람 인쇄 53쪽은 본문 줄간격·여백 조정을 허용하고, 60쪽은 붙임 앞 빈 줄을 두거나 두지 않아도 된다고 명시한다. 같은 묶음의 ‘한곳에 정리한 공문서 작성법’ 7쪽은 기본 줄간격 123%를 안내한다. 묶음이 2026년 기준이라는 사실이 개별 첨부물 모두 2026년 개정판임을 의미하지 않는다.

배포 자리표시자 도우미는 본문과 첫 붙임 사이에 본문과 같은 스타일의 빈 문단 하나를 넣으며 붙임 항목 사이에는 빈 문단을 추가하지 않는다. 이것은 새 양식 생성 권한이나 기존 현재본 전체의 빈 줄 자동 변경 규칙이 아니다. 일반 현재본은 첫 붙임의 직전 문단을 확인하고 지정 양식과 요청 범위를 따른다. 문단 위아래 여백과 빈 줄을 중복하지 않으며 ‘국가 규정상 반드시 한 줄’로 설명하지 않는다.

편람 147쪽의 ‘일반적인 줄 간격 130% 이상’은 제3절 서식 설계 기준이다. 공문 본문의 일률적 최소 줄간격으로 확대 적용하지 않는다.
