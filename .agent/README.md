# 공통 실행 도구

- `shared/`: 공통 실행 코드·검증·전문 지침·빈 양식
- `index/`: 업무 경로와 고정 런타임 사양
- `cache/`: 설치할 컴퓨터에서 생성되는 실행 환경. 배포에 포함하지 않는다.

업무별 원본·현재본·이전본·작업 기록은 선택한 업무폴더의 `.ai/`에 둔다. 스킬 진입점은 [프로젝트 스킬](../.agents/skills/), 초기 설정은 [설치 안내](../INSTALL.md)를 따른다.

사용자가 제공한 파일은 설정된 받은자료에 원본 사본을 자동 보관하며 원래 파일을 옮기거나 수정하지 않는다. 문서·표·텍스트 산출물은 사용자 지정 초안/양식, 등록된 현재본, 명시적으로 선택한 이전 문서를 먼저 열어보고 필요한 내용만 채운다. 공통 빈 양식은 사용자 선택 전에는 기본 기준본이 아니다. 기준본 부재·읽기 실패·모호한 선택은 관련 작성의 중단 조건이다.
