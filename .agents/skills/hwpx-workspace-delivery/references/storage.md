# 문서 보관과 수정 이력

학교 문서의 현재본·작업본·수정 이력은 선택한 사람 업무폴더 안에 둔다. `.agent`에는 새 학교 초안·미리보기·사본을 만들지 않는다.

- 작업본: `Start-HwpxWork.ps1`의 반환 경로인 `.ai/jobs/.../wip/docs/`를 사용한다. 산출물당 작업본 하나를 유지하고 같은 목적·입력의 진행 중 job은 재사용한다. 사람이 작업본을 수정했다면 그 내용도 현재본과 대조해 보존한다.
- 원본: 선택한 파일만 `.ai/originals`에 보관한다. 동일한 접수와 기존 legacy 보존 기록은 재사용한다. 실행기에 필요한 변환본·검증 기록은 같은 job 안에 둔다.
- 사용자 제공자료: 파일을 제공받으면 설정된 받은자료에 원본 사본을 자동 보관한다. 업무의 `.ai/originals` 역할별 접수와 구분하며 원래 파일을 이동·수정하지 않는다. 접근 불가 파일은 보관됐다고 기록하지 않는다. 실행·충돌 보존은 [접수](artifacts.md)를 따른다.
- 이전본: 앞으로 실제 교체·제외하는 현재 파일은 `.ai/revisions/<SHA256><확장자>`에 보존한다. 사용자 수정 여부를 추측하여 버리지 않고 실제 현재 바이트를 보존하며, 같은 내용의 객체는 해시를 검증해 재사용한다. `.ai/work.json.revisionHistory`에는 사건별 대상 현재본·보존 경로·해시를 기록한다. 현재본 이름에는 fix를 붙이지 않고, 동일 결과 재시도·무변경 파일은 새 보존 파일이나 게시 사건을 만들지 않는다. 기존에 등록된 fix 이력은 별도 정리 요청 없이 이동·삭제하지 않는다.
- 복구: 게시 실패는 도구의 보존 매핑에서 현재본을 복원한다. 재사용한 보존 객체는 실패 정리로 삭제하지 않고 새 객체만 안전하게 정리한다. 성공 영수증에서 참조하는 파일은 검증에 필요하므로 자동 정리하지 않는다. 더 이상 필요 없는 중간물을 정리할 때도 업무폴더 안에서 복구 경로와 참조를 함께 관리한다.

`previous_versions`는 새로 만들지 않는다. 업무폴더의 기존 자료는 별도 정리 요청 없이 옮기거나 삭제하지 않는다. 하네스에는 업무별 작업·복구 기록을 보관하지 않는다. 현재본을 과거 AI 결과로 자동 대체하지 않는다.

유지보수의 지침·코드 이력은 [유지보수 스킬](../../workspace-maintenance/SKILL.md)에서 관리한다.
