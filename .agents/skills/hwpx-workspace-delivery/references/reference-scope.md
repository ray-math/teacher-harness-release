# 업무별 기준자료 선택

대상 업무가 정해지면 사용자가 이미 제공한 파일·경로와 `Get-WorkContext.ps1 -WorkFolder <업무폴더>`의 유효한 자료 선택을 먼저 확인한다. 개별 `.ai/reference-scope.json`이 있으면 그것을 우선하고, 없으면 사용자가 연결한 반복 업무 그룹의 자료를 사용한다. 충분한 자료가 있으면 재질문하지 않는다. 업무에 필요한 근거가 정해지지 않았을 때 필요한 자료만 묻는다. 세 종류를 모두 요구하지 않는다.

## 초안·양식을 먼저 열기

문서·표·텍스트 산출물을 작성하기 전에 다음 순서로 기준본을 선택하고 실제 내용을 연다.

1. 사용자가 이번 업무에서 지정한 기존 초안이나 양식.
2. 해당 업무에 등록된 현재 문서.
3. 사용자가 명시적으로 선택한 이전 문서. 빈 양식뿐 아니라 완료된 계획서·공문·표도 사용할 수 있다.

표 구조·문단·배치 등 기존 형식을 확인한 뒤 현재 근거로 요청한 내용만 채운다. 이전 문서의 일정·대상·문서번호 등은 올해 사실로 상속하지 않는다. 여러 후보 중 기준이 모호하거나 파일을 읽을 수 없으면 선택 또는 읽을 수 있는 파일을 요청하고 관련 작성을 멈춘다. 초안과 양식이 모두 없으면 “사용할 기존 초안이나 양식을 보내 주세요.”라고 요청하며 새 양식으로 대체하지 않는다. ‘자료 없이 시작’, ‘새 초안’, ‘최종본’도 이 요구를 우회하지 않는다. 하네스에 들어 있는 범용 빈 assets는 사용자가 선택하기 전에는 기본 기준본이 아니다. 질문·분석·업무계획 논의는 이 요구의 대상이 아니다.

## 자료 선택 기록

- 사용자 답변을 `Set-WorkReferenceScope.ps1 -WorkFolder <업무폴더>`의 `-ManualPath`, `-CurrentPath`, `-PriorPath`로 저장한다. 각 인자는 파일 또는 폴더 배열이다. 업무폴더나 연간 업무 묶음 안의 경로는 각각의 기준 위치에 대한 상대 경로로 보관한다. `-NoReferences`는 추가 참고자료를 사용하지 않는다는 선택만 기록하며 초안/양식 없는 작성을 허용하지 않는다.
- 작년 서류가 업무폴더 안에 있어도 사용자가 선택한 경로만 쓴다. 폴더명·연도로 추정하거나 고정 `source`, `manuals`, 공문함을 검색하지 않는다. 같은 그룹으로 연결한 반복 회차는 선택 자료를 공유한다. 연결되지 않은 새 업무·다음 학년도는 자동 상속하지 않는다. 공통 자료의 선택·변경은 [반복 업무 기록](../../work-planning/references/repeated-work.md)을 따른다.
- `Find-HwpxContext.ps1 -WorkFolder <업무폴더>`는 저장된 범위와 해당 업무에 등록된 현재본을 읽는다. 사용자가 이번 요청에서 직접 지정한 `-SeedFile`·`-PriorFolder`는 그 요청의 입력으로 바로 사용할 수 있다.
- `status=needs_input`이면 이유를 확인하고 필요한 경로만 묻는다. 선택이 없거나 폴더가 사라졌다는 사실을 “자료가 없다”는 근거로 바꾸지 않는다. 숨김 작업·복구 폴더, 링크 경로, fix 이력은 폴더 검색에서 제외한다.
- 범위를 바꿀 때만 선택 파일을 갱신한다. 자료 선택은 원본의 이동·수정·삭제나 공식 사실의 확정을 뜻하지 않는다. 사용자가 제공한 파일의 받은자료 사본은 [접수](artifacts.md)에 따라 자동 보관하고, 실제 사용한 파일만 역할별로 업무에 접수해 해당 업무폴더에 결과를 만든다.
