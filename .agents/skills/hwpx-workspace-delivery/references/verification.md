# 문서 검사와 종료

요청과 선택한 연산에 필요한 검사만 수행한다. 입력·출력·관련 도구 버전이 같은 성공 영수증은 재사용한다. 게시 도구가 요구하는 해시·출처·게이트 확인은 그대로 실행하되, 그 영수증을 얻기 위해 이미 성공한 편집·추출·렌더를 다시 수행하지 않는다. 구체적 실패·변경된 의존성·추가 요청 없이 검사 범위를 확대하지 않는다.

| 작업 | 완료 근거 |
|---|---|
| 확인·분석 | 항목별 판정·출처 위치·읽기 제한. 학교 파일·접수·현재 등록 변경 없음 |
| 일반 작성·수정 | 먼저 열어 확인한 기존 초안/양식과 선택 근거, 현재 근거와 변경 내용 대조, 기존 배치·무관한 내용 보존, 파일 무결성, 게시 영수증 |
| 동일 양식 취합 | 출처별 제출 레코드, 누락·중복·학번/성명 충돌·인원, 변경/비변경 셀과 실행기·게시 영수증 |
| 전체 문서 병합 | 입력 해시·원문 순서·패키지·실행기의 필수 네이티브 재열기·게시 영수증 |
| 요청된 콘솔 보고 | 보고 스키마·안전 표시·등록 보존·갱신 영수증. 문서 수정/운영 완료의 증거가 아님 |

취합은 파일 수와 과목 수가 같다고 가정하지 않는다. 한 파일의 여러 제출 행을 유지하고 공란·0·없음·충돌을 구분한다. 예상 인원은 보조 검증값이며 원문을 대신하지 않는다. 합계 일치만으로 레코드 반영을 확정하지 않는다.

일반 작업은 내용·무결성에서 끝난다. [서식 허가와 시각 검사 범위](../SKILL.md#내용과-서식-범위)는 문서 스킬을 따른다. 실행기 재열기는 외관 검사와 구별한다. 오류가 발생하면 해당 부분만 진단한다.

결과 위치, 수행한 검사, 미확정 사항을 채팅으로 보고한다. 완료 표시를 위해 확인만 요청된 원문을 저장하거나 별도 설명 파일을 만들지 않는다. 공식 결재·제출·통지·운영 완료는 실제 근거가 필요하다.

문서 납품에는 공통 도구의 유지보수 회귀 테스트를 실행하지 않는다. 업무별 제작 스크립트도 해당 산출물의 내용·무결성으로 확인한다. 공통 실행 코드나 지침 자체의 수정은 별도 유지보수 요청의 범위다.
