# 업무 설계와 개선

사용자가 원하는 결과와 완료 기준, 제시한 업무흐름을 바탕으로 필요한 일을 정한다. 이미 제공한 정보로 진행하고 판단에 필요한 누락만 묻는다. 채팅에서 절차·구조를 논의할 때는 파일·job을 만들지 않는다.

질문·분석·업무계획 논의에는 문서 양식을 요구하지 않는다. 문서·표·텍스트 문안 작성까지 요청되면 [문서 처리](../hwpx-workspace-delivery/SKILL.md)의 기존 초안/양식 우선 원칙을 적용한다. 사용자 지정 기준본 → 등록된 현재본 → 명시적으로 선택한 이전 문서를 먼저 열고 현재 근거로 필요한 내용만 채운다. 초안과 양식이 모두 없거나 읽을 수 없거나 선택이 모호하면 관련 작성은 멈추고 필요한 파일·선택을 요청한다. ‘자료 없이 시작’이나 새 업무 계획은 새 양식 작성 근거가 아니다. 제공받은 파일은 계획 논의만 하는 중에도 받은자료에 원본 사본을 자동 보관한다.

반복 입력·자료 찾기·재작업·단계 누락을 줄일 효과가 분명하면 문제, 바꿀 방법, 기대 효과를 짧게 제안한다. 기존 기준자료의 값을 재사용하고 같은 정보를 위한 새 관리 문서를 늘리지 않는다. 매 요청마다 제안을 반복하지 않는다. 확정한 공통 처리 방법은 [반복 업무 기록](references/repeated-work.md)에 남겨 다음 회차에 적용한다.

실제 배치는 [업무폴더 선택](../hwpx-workspace-delivery/references/work-folder.md)으로 대상과 진행 중 job을 재사용한다. 연간 업무흐름은 업무 보관함 바로 아래에 둔다. 업무 분류는 사용자가 확정한 번호 범위로 표시한다. 새 종류의 번호대가 미정이면 폴더 생성 전에 한 번 묻고, 답을 공통 기록에 저장한다. 번호대·분류의 의미를 임의로 정하거나 매년 고정하지 않는다. 사용자가 명시적으로 고정한 공통 분류는 [반복 업무 기록](references/repeated-work.md)의 공통 설정을 우선한다. 이미 확정한 분류에 속하는 후속 업무는 저장된 기준을 재사용하고, 소속이 모호할 때만 확인한다.  반복 회차 폴더를 보관함 바로 아래에 둔다. 학년도는 연간 묶음에서 관리하며 하위 업무명에 반복하지 않는다. 분류를 위해 빈 상위 폴더를 만들지 않는다.

사용자 흐름으로 충분하면 바로 적용한다. 이전 관행에서 빠진 절차를 찾을 때만 [기준자료 선택](../hwpx-workspace-delivery/references/reference-scope.md)을 확인한다. 자료 선택은 공식 기준의 확정이 아니며 전년도 시기·대상·결재 의무를 올해에 그대로 적용하지 않는다.

업무 안에서 여러 산출물은 번호 폴더, 하나는 번호 파일, 산출물 없는 단계는 `none`으로 배치한다. 주요 현재본은 업무 루트에 둔다. 후속 변경은 영향받는 단계만 바꾸고 같은 작업의 ID·경로를 유지한다. 중간 추가는 삽입 번호를 사용한다. 기존 파일 이동은 별도 요청 범위에서 참조와 등록을 함께 갱신한다.

계획을 저장·적용하거나 지정 자료를 탐색할 때만 [계획 형식](references/workflow-format.md)과 `Prepare-WorkWorkflow.ps1`을 사용한다. 배치 작업에 job이 없으면 선택한 업무 안에서 `New-HwpxJob.ps1`을 사용한다. 문서 작성까지 요청받았으면 [문서 처리](../hwpx-workspace-delivery/SKILL.md)에 같은 업무·job·자료를 넘긴다. 일반 업무의 분류·공통 결정 저장은 하네스 유지보수가 아니다.

`Start-HwpxWork.ps1`로 문서 작성 없는 계획·배치만 접수해야 할 때는 `-Purpose Workflow`를 사용한다. 이 job은 문서 완료·게시를 허용하지 않는다. 문서 작성까지 요청되면 기본 `-Purpose Document`와 실제 기준본 역할로 접수하고 기존 초안/양식 확인을 먼저 해결한다. `Workflow`를 기준본 없는 문서 작성의 우회로 사용하지 않는다.

결과는 채팅으로 보고한다. 설명 TXT·현황판·대체 업무흐름을 자동 생성하지 않는다. HTML 생성·갱신을 명시적으로 요청한 경우에만 `-UpdateConsole`을 사용한다.
