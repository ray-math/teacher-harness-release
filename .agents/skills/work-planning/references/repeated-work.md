# 반복 업무와 분류 기록

연간 업무 묶음의 `.ai/work-groups/<groupId>.json`에 사용자가 확정한 업무 분류, 업무흐름 원문의 경로, 선택한 기준자료, 공통 처리 방법만 저장한다. 각 회차는 보관함 바로 아래에 두고 `.ai/work.json`의 `groupId`와 `groupCategoryCode`로 연결한다. 공통 기준자료 사본·설명 TXT·추가 현황판은 만들지 않는다.

## 분류를 정할 때

- 기존 그룹의 분류표와 대화에서 이미 확정한 번호대를 먼저 확인한다. 평가·고사·최성보 같은 특정 업무명과 번호는 공통 코드나 지침의 기본값이 아니다.
- 새로운 종류의 번호대가 미정이면 생성 전에 “이 업무는 어느 번호대로 둘까요?”라고 묻는다. 확인 전에 임의 번호로 만들어 나중에 옮기지 않는다.
- 한 번 정한 분류는 같은 연간 묶음에서 재사용한다. 분류가 명확한 새 회차는 그 범위의 미사용 번호를 사용하되, 기존 순번·이름을 바꾸지 않는다. 범위가 차거나 분류가 모호하면 필요한 결정만 묻는다.
- 새 연도·담당 업무는 사용자가 정한 흐름과 분류로 시작한다. 사용자가 명시적으로 유지하기로 한 공통 설정만 계속 적용한다. 과거 업무 기록·기준자료·회차별 예외는 자동 상속하지 않는다.

## 읽기와 적용

`powershell -NoProfile -ExecutionPolicy Bypass -File .agent/shared/Get-WorkContext.ps1 -WorkFolder <업무폴더>`로 연결된 분류, 공통 결정, 개별 예외, 유효한 자료 선택을 함께 읽는다. 같은 요청에서 읽은 결과는 재사용하고 관련 설정이 바뀌면 다시 읽는다.

공통 결정은 `key`로 구분한다. `appliesTo`가 비어 있으면 해당 그룹 전체, 값이 있으면 명시한 분류에만 적용한다. 업무별 `decisionOverrides`가 같은 키를 덮어쓰며 `disabled`는 해당 업무에서만 제외한다. 한 고사의 날짜·명단·예외를 다른 회차에 전파하지 않는다. 그룹 갱신은 다음 요청의 기준을 바꾸며 이미 만든 문서를 자동 재작성하지 않는다.

개별 `.ai/reference-scope.json`이 있으면 그 선택 전체를 우선한다. 없을 때만 명시적으로 연결된 그룹의 선택을 상속한다. 자료 미선택·누락은 필요한 경로를 질문하고, 묶음 전체를 대신 검색하지 않는다. `noReferences`는 추가 참고자료를 사용하지 않는다는 선택이며, 문서 작성에 필요한 기존 초안/양식 확인을 생략하는 허가가 아니다. 완료된 이전 문서도 사용자가 명시적으로 선택하면 기준본으로 활용할 수 있으나 일정·명단 등 현재 사실은 별도로 확인한다.

## 확정 내용을 저장할 때

`Set-WorkGroup.ps1 -GroupId <안정적인 ID> -DefinitionPath <임시 JSON> -ConfirmedByUser`로 새 그룹이나 변경한 필드만 저장한다. `-ConfirmedByUser`는 실제 대화의 명시적 결정에 근거한다. 이미 합의한 분류·방법을 저장하기 위해 재승인을 묻지 않는다. AI가 제안만 한 내용은 확정 기록으로 저장하지 않는다.

정의의 필드는 다음과 같다. JSON은 에이전트가 임시폴더에서 준비하며 사용자에게 작성시키지 않는다.

| 필드 | 내용 |
|---|---|
| `title`, 선택적 `year` | 사용자가 정한 업무 묶음명과 학년도 |
| `categories` | `{code,title}` 배열. 코드의 의미는 사용자 결정 |
| `workflowPath` | 사용자가 제시한 연간 업무흐름 원문 경로. 내용 복제 금지 |
| `referenceScope` | `noReferences`와 `roots: [{role,path}]`. role은 `manual`, `current-source`, `prior-source` |
| `decisions` | `{key,text,appliesTo:[]}` 배열. 확정한 공통 처리 방법만 저장 |

배열을 갱신할 때는 기존 항목을 읽어 보존하고 변경분을 반영한 전체 배열을 보낸다. 다른 분류의 규칙·자료를 덮어쓰지 않는다. 자료와 업무흐름은 보관함 내부면 상대경로로, 명시적으로 선택한 외부 자료면 절대경로로 저장한다.

이미 등록된 새 회차는 `Set-WorkGroup.ps1 -GroupId <ID> -WorkFolder <경로> -CategoryCode <확정 코드> -ConfirmedByUser`로 연결한다. 사용자와 이미 정한 반복 업무의 후속 회차이면 그 합의를 근거로 연결한다. 폴더 이름만으로 그룹을 추정하지 않는다.

업무 하나에만 적용할 확정 예외는 `Set-WorkDecision.ps1 -WorkFolder <경로> -Key <키> -Text <내용> -ConfirmedByUser`로 저장한다. 공통 결정을 그 업무에서 제외할 때는 `-Disabled`, 예외를 지우고 공통 기준으로 돌아갈 때는 `-RemoveOverride`를 쓴다. 새 공통 결정은 해당 그룹 정의의 `decisions`를 갱신한다.

## 연간 보관과 이동

현재 연간 묶음을 나중에 `2026업무`처럼 보관하므로 회차 폴더명에 연도를 반복하지 않는다. 연간 묶음 내부의 상대경로 자료와 그룹 연결은 함께 이동한다. 외부 자료 경로가 사라졌으면 다시 선택한다. 새 연도의 업무는 새 보관함에서 시작한다.

보관한 폴더를 참고자료로 선택하는 데는 공통 설정 변경이 필요 없다. 작업 대상 보관함 자체를 바꾸려는 요청이면 [설치·이동 안내](../../../../INSTALL.md)의 명시적 경로 선택 절차를 따른다. 기존 날짜 폴더의 이름 변경은 등록·링크 이동을 포함하는 별도 작업이다.
