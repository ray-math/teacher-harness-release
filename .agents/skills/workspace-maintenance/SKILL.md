# 작업공간 유지보수

설정의 정본은 `.agent/index/`, 실행 도구는 `.agent/shared/`, 업무별 지침은 `.agents/skills/`다. 경로는 `.agent/index/delivery-system.json`에서 읽는다. 지침을 바꿀 때 모든 세션에 필요한 원칙만 AGENTS에 남기고, 업무 규칙은 소유 스킬 한 곳에서 관리한다. 같은 이름의 개인 스킬을 프로젝트에 중복 등록하지 않는다.

명시적으로 요청된 유지보수에서만 공통 도구와 지침을 변경한다. 업무 보관함의 그룹 설정·기준자료·확정 개선점은 업무 데이터이며 이 스킬을 호출하지 않는다. 필요한 코드 임시본·합성 검사는 시스템 임시폴더에 두고, 과거 학교자료나 작업별 복구본을 하네스에 축적하지 않는다. 프로젝트 스킬은 배포 폴더의 정본을 사용하고 전역 개인 스킬 사본을 자동 등록하거나 동기화하지 않는다. 새 규칙의 사례·경과를 상시 지침에 계속 덧붙이지 않는다.

학교 파일·원본은 유지보수 테스트로 바꾸지 않는다. 사용자가 정리를 요청한 기존 자료·복구 기록은 호출 관계와 설치본 의존성을 확인하고 필요한 정비 후 제거한다. 현재 설정·실행기는 과거 진단과 구분한다. 삭제 경로가 요청 범위 안인지 확인하고 reparse 경로를 거부한다. 요청 없는 저장소 초기화·구조 변경은 하지 않는다. 개인정보·비밀을 채팅이나 공통 색인에 남기지 않는다.

| 변경 대상 | 필요한 확인 |
|---|---|
| 지침·링크·스킬 | 규칙의 소유권·충돌, 실제 경로/앵커, 스킬 형식과 대표 요청의 선택 결과 |
| 실행 코드·설정 동작 | [구성요소별 검사](references/checks.md)에서 영향받는 검사만 선택 |
| 콘솔 생성기·파일 열기 실행기 코드 | [콘솔 계약](references/console.md)의 해당 절; 명시적으로 요청된 기능만 변경 |
| HWPX 런타임 설치·복구 | [런타임 유지보수](../../../.agent/shared/hwpx-runtime/maintenance.md) |
| 새 환경 설치·업데이트 | [설치 안내](../../../INSTALL.md); 업무 중 자동 설치·갱신 금지 |

업무별 `.ai/jobs/`의 일회성 문서 제작 스크립트는 해당 문서 작업의 일부다. 공통 도구를 고치지 않는다면 이 스킬의 회귀 검사를 추가하지 않는다. 지침만 바꾸면 형식·링크·대표 요청 판단을 확인하고, 실행 코드도 바꾼 경우에만 영향받는 회귀 검사를 선택한다.

Windows PowerShell 5.1로 스크립트를 실행한다: `powershell -NoProfile -ExecutionPolicy Bypass -File <경로> <인자>`. 작업공간 구조만 점검할 때는 `Test-HwpxWorkspace.ps1 -StructureOnly`를 사용한다. 일반 유지보수 때문에 사람 업무폴더나 학교 산출물을 만들지 않는다.

격리된 합성 fixture 검사는 요청 범위에서 실행·수정·재검사까지 진행한다. 관련 검사 통과 후 결과와 한계를 채팅으로 보고한다. 새 실패·변경 영향이 없으면 추가 감사로 확대하지 않는다. 준비만 요청받으면 지침과 연결 확인에서 끝낸다.

효율 분석을 요청받으면 작업의 기존 영수증과 해당 대화 로그만 읽는다. `.agent/shared/measure_workflow_usage.py --rollout <정확한 JSONL 경로> --before <선택한 종료시각>`은 내용 원문 없이 요청별 기록 시간·토큰·도구 응답량을 요약한다. 완료 구간의 경과 시간에는 대기가 포함되며, 하위 에이전트 시간은 병렬일 수 있어 단순 합산하지 않는다. 토큰은 입력·캐시 입력·출력을 구분하고 캐시를 입력에 다시 더하지 않는다. 파일 크기나 출력 문자 수를 토큰 수로 부르지 않는다. 기존 영수증이 덮어써졌거나 하위 에이전트 로그가 없으면 누락 범위를 밝힌다.

독립된 하위 작업을 위임할 때는 필요한 요청·경로·제약·완료 기준만 전달하고, 전체 대화가 필요한 경우에만 전체 이력을 넘긴다. 담당자가 확인한 결과는 근거 경로와 변경 영향으로 통합하며 같은 탐색과 검사를 다시 수행하지 않는다. Windows PowerShell 5.1용 한글 포함 스크립트는 UTF-8 BOM으로 저장한다.
